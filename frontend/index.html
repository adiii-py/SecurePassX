T1566.002 Initial Access

Spearphishing Link

Adversaries send targeted emails with malicious links to lure victims into visiting sites designed to harvest credentials or execute drive-by payloads.

Triggers: Deceptive hyperlinks, Lookalike domains, High-risk TLDs
T1566.001 Initial Access

Spearphishing Attachment

Adversaries attach weaponized files (.iso, .lnk, .exe, .html) disguised as legitimate documents to gain code execution upon user interaction.

Triggers: Dangerous file extensions, Double extensions, MOTW bypass containers
T1583.001 Resource Development

Acquire Infrastructure: Domains

Adversaries register lookalike domains, acquire newly registered domains (NRDs), and establish DNS records to conduct phishing campaigns.

Triggers: Domain age < 30 days (NRD), Spamhaus abused TLDs, Fast-flux DNS
T1036 Defense Evasion

Masquerading / Typosquatting

Manipulating features of domain names, sender names, or page titles to mimic legitimate, trusted brands (Microsoft, Google, PayPal, Banks).

Triggers: Levenshtein distance typosquatting, Cyrillic IDN homoglyphs, Punycode (xn--)
T1556 Credential Access

Modify Authentication Process / Harvesting

Adversaries deploy fake login portals with HTML password inputs that exfiltrate entered user credentials to offshore drop servers.

Triggers: Password input posting to external/mismatched action URL

Spearphishing via Service

Leveraging compromised or spoofed email relay services with invalid SPF and DMARC alignments to impersonate trusted corporate entities.

Triggers: SPF fail/softfail, DKIM failure, DMARC alignment failure

SOC Tier-1 Phishing Triage Standard Operating Procedure (SOP)

Operational guide for Tier-1 analysts conducting first-response phishing email and suspicious URL triage.

Step 1: Ingestion & Defanging

Never click raw URLs or open attachments on non-isolated host machines. Always ensure URLs and IPs are defanged (hxxps://, [.]) before sharing in ticketing systems or chat channels.

Step 2: Lexical & Authentication Validation

Verify SPF, DKIM, and DMARC headers. Cross-reference the visual Header From address with the technical Return-Path and Reply-To envelopes. Check for newly registered domains (NRDs < 30 days old) and brand lookalikes.

Step 3: Determine Severity & Escalation

• Score 0–29 (Safe): Close alert with resolution notes.
• Score 30–59 (Suspicious): Place on watch; verify with sender through out-of-band communication.
• Score 60–100 (High Risk / Phishing): Initiate containment playbook immediately.

Step 4: Containment & Remediation

1) Block domain/URL on perimeter firewalls and web proxies. 2) Execute tenant-wide message trace and hard-purge the malicious email from all recipient inboxes. 3) For any user who clicked or entered credentials, reset password, revoke active sessions, and verify MFA tokens.
